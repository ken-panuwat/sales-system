# ระบบขายสินค้า (Laravel 12 + MySQL / XAMPP)

ระบบขายสินค้า รองรับ 3 บทบาท: **ผู้ดูแลระบบ**, **เจ้าของร้าน**, **ลูกค้า**

## ความต้องการของระบบ
- PHP 8.2+ และ Composer
- MySQL / MariaDB (XAMPP + phpMyAdmin)
- ต่ออินเทอร์เน็ตขณะใช้งาน (ระบบโหลด Bootstrap, SweetAlert2, Chart.js, pdfmake และฟอนต์จาก CDN)

## ฟีเจอร์หลัก
**ทุกบทบาท**
- เข้าสู่ระบบ / ออกจากระบบ / โปรไฟล์ (เปลี่ยนรูป ชื่อ เบอร์ รหัสผ่าน; ไม่มีรูปแสดงอักษรตัวแรกของชื่อ)
- รหัสผ่านต้องยาวอย่างน้อย 6 ตัว มีตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และอักขระพิเศษ
- ป๊อบอัพแจ้งผล (สำเร็จ / ไม่สำเร็จ / ข้อมูลไม่ถูกต้อง) และป๊อบอัพยืนยันก่อนทำรายการสำคัญ
- ข้อมูลอัปเดตแบบเรียลไทม์ (ดึงข้อมูลใหม่อัตโนมัติทุก 5 วินาที)

**ลูกค้า**
- เลือกซื้อสินค้า: กรองตามหมวดหมู่ / สินค้าโปรโมชัน, ค้นหา, แบ่งหน้า (ก่อนหน้า / ถัดไป)
- การ์ดสินค้าแสดงรูปเต็ม เลือกจำนวนและใส่ตะกร้าได้ทันที คลิกการ์ดเพื่อดูรายละเอียดสินค้า
- ตะกร้า → ชำระเงิน: คำนวณค่าส่ง (Flash Express) แสดงก่อนยืนยัน
- ชำระเงิน 2 วิธี: โอนผ่านธนาคาร (แนบสลิป) และ QR PromptPay
- ติดตามสถานะ: ชำระเงินสำเร็จ → ยืนยันออเดอร์ → แพ็คสินค้า → จัดส่งสินค้าให้บริการขนส่ง พร้อมเลขพัสดุ

**เจ้าของร้าน / ผู้ดูแลระบบ**
- แดชบอร์ดพร้อมกราฟ (ยอดขาย 14 วัน, สถานะคำสั่งซื้อ, สินค้าขายดี, ผู้ใช้ตามบทบาท)
- จัดการสินค้า: เพิ่ม/แก้ไข/ลบ, รหัสสินค้ารันอัตโนมัติ, เลือกจำนวนแถว 10/20/50/100/ทั้งหมด, ตั้งโปรโมชัน (ลดเป็น % หรือบาท กำหนดช่วงวันที่ได้)
- จัดการคำสั่งซื้อ: ตรวจสลิปและอนุมัติ/ไม่อนุมัติ (อนุมัติได้เมื่อลูกค้าแจ้งชำระแล้วเท่านั้น), อัปเดตสถานะการจัดส่ง
- สร้างรายการส่ง (ออกเลขพัสดุ) และพิมพ์ใบปะหน้ากล่องพัสดุ
- รายงานยอดขายรายวัน / รายเดือน ดาวน์โหลดหรือพิมพ์เป็น PDF ฟอนต์ Sarabun

**ผู้ดูแลระบบเท่านั้น**
- จัดการผู้ใช้ (เพิ่ม/แก้ไข/ลบ กำหนดบทบาท)

## วิธีติดตั้ง
```bash
git clone https://github.com/<ชื่อผู้ใช้>/sales-system.git
cd sales-system
composer install
copy .env.example .env        # Windows (macOS/Linux ใช้ cp)
php artisan key:generate
```

1. สร้างฐานข้อมูลเปล่าใน phpMyAdmin (collation `utf8mb4_general_ci` หรือ `utf8mb4_unicode_ci`)
2. ตั้งค่าใน `.env`
   ```
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=ชื่อฐานข้อมูล
   DB_USERNAME=root
   DB_PASSWORD=
   ```
3. รันคำสั่ง
   ```bash
   php artisan migrate --seed
   php artisan storage:link
   php artisan serve
   ```
   เปิด http://127.0.0.1:8000

> ถ้าใช้ไฟล์ SQL ที่แนบมา (`database/`) ให้นำเข้าผ่านแท็บ "import" ใน phpMyAdmin แทน `migrate`

## การตั้งค่าเพิ่มเติม (`.env`)
```
# บัญชีรับเงินของร้าน (ข้อความภาษาไทยต้องใส่เครื่องหมายคำพูด)
SHOP_BANK_NAME="ธนาคารกสิกรไทย"
SHOP_BANK_ACCOUNT_NO="000-0-00000-0"
SHOP_BANK_ACCOUNT_NAME="ชื่อบัญชี"
SHOP_PROMPTPAY_ID="เบอร์โทร 10 หลัก หรือเลขบัตร 13 หลัก"
SHOP_PROMPTPAY_NAME="ชื่อร้าน"

# ค่าขนส่ง (Flash Express — โหมดจำลอง)
SHIPPING_DRIVER=mock
SHIPPING_BASE_FEE=40
SHIPPING_INCLUDED_ITEMS=3
SHIPPING_EXTRA_PER_ITEM=10
SHIPPING_FREE_OVER=1000        # 0 = ไม่มีส่งฟรี

# ข้อมูลผู้ส่งบนใบปะหน้า
SHOP_SENDER_NAME="ชื่อร้าน"
SHOP_SENDER_PHONE="0800000000"
SHOP_SENDER_ADDRESS="ที่อยู่ร้าน"
```
หลังแก้ `.env` ให้รัน `php artisan optimize:clear`

## รายงาน PDF
สร้างในเบราว์เซอร์ด้วย pdfmake และโหลดฟอนต์ Sarabun จาก CDN (ต้องต่ออินเทอร์เน็ต)
หากต้องการใช้แบบออฟไลน์ ให้วางไฟล์ `Sarabun-Regular.ttf` และ `Sarabun-Bold.ttf` ไว้ที่ `public/fonts/`
ปรับขนาดอักษรที่ `defaultStyle.fontSize` ใน `resources/views/reports/index.blade.php`

## ข้อจำกัดที่ควรรู้
- **การขนส่ง:** ยังเป็นโหมดจำลอง ค่าส่งคำนวณตามสูตรใน `config/shipping.php` และเลขพัสดุเป็นเลขสุ่ม
  เมื่อเชื่อม Flash Express จริง ให้แก้ฟังก์ชัน `quote()` และ `createShipment()` ใน `app/Support/Shipping.php` แล้วตั้ง `SHIPPING_DRIVER=flash`
- **การชำระเงิน:** เป็นแบบ "ลูกค้าแจ้งชำระ + ร้านตรวจและอนุมัติ" ยังไม่ตรวจยอดเข้าบัญชีอัตโนมัติ
  ต้องใช้ Payment Gateway หรือ Open API ของธนาคาร (เช่น Omise, 2C2P, SCB Open API) ที่ร้านสมัครเอง
- **เรียลไทม์:** ใช้การดึงข้อมูลซ้ำทุก 5 วินาที ไม่ใช่ WebSocket
- ยอดขายนับเฉพาะคำสั่งซื้อที่ชำระแล้วและไม่ถูกยกเลิก และรวมค่าส่ง
