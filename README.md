# ระบบขายสินค้า (Laravel 12 + MySQL/XAMPP) — ชุดอัปเดตรอบที่ 2

ชุดนี้มี "เฉพาะไฟล์ที่แก้ไข/เพิ่มใหม่" ให้คัดลอกไปวางทับโปรเจกต์เดิม (โครงสร้างโฟลเดอร์ตรงกับโปรเจกต์)

## วิธีอัปเดต
1. คัดลอกโฟลเดอร์ทั้งหมดในชุดนี้ไปวางทับโปรเจกต์เดิม (Replace ไฟล์ซ้ำ)
2. (ไม่บังคับ) เพิ่มใน `.env` เพื่อตั้งบัญชีรับเงินของร้านจริง
   ```
   SHOP_BANK_NAME="ธนาคารกสิกรไทย"
   SHOP_BANK_ACCOUNT_NO="123-4-56789-0"
   SHOP_BANK_ACCOUNT_NAME="ร้านค้าสีเขียว"
   SHOP_PROMPTPAY_ID="0800000002"
   SHOP_PROMPTPAY_NAME="ร้านค้าสีเขียว"
   ```
   (ถ้าไม่ใส่ จะใช้ค่าตัวอย่างใน `config/shop.php`)
   `SHOP_PROMPTPAY_ID` = เบอร์โทร 10 หลัก หรือเลขบัตรประชาชน/ผู้เสียภาษี 13 หลักที่ผูก PromptPay
3. รันคำสั่ง (ไม่ต้อง --seed ซ้ำ ข้อมูลเดิมไม่หาย)
   ```
   php artisan migrate
   php artisan optimize:clear
   php artisan storage:link
   ```
   `storage:link` ทำครั้งเดียวพอ (ถ้าเคยทำแล้วจะขึ้นว่ามีอยู่แล้ว)

## สิ่งที่เปลี่ยนในรอบนี้
1. ป๊อบอัพ (SweetAlert2) เมื่อสำเร็จ/ไม่สำเร็จ/ข้อมูลไม่ถูกต้อง รวมถึงเข้าสู่ระบบ ออกจากระบบ และหน้าต่างยืนยันก่อนลบ/เปลี่ยนสถานะ/อนุมัติ
2. ฟอนต์แยกกัน: หัวข้อใช้ Prompt, เนื้อหาย่อยใช้ Noto Sans Thai (ปรับที่ `--font-head` / `--font-body` ใน `public/css/app.css`)
3. ทุกช่องรหัสผ่านมีปุ่มลูกตา เริ่มต้นเป็นปิดลูกตา (ซ่อนรหัสผ่าน)
4. แดชบอร์ดมีกราฟ: ยอดขาย+จำนวนคำสั่งซื้อ 14 วัน, สถานะคำสั่งซื้อ, สินค้าขายดี, ผู้ใช้ตามบทบาท (เฉพาะผู้ดูแลระบบ)
5. หน้าสินค้าเลือกจำนวนแถว 10 / 20 / 50 / 100 / ทั้งหมด พร้อมแบ่งหน้า
6. ชำระเงิน 2 แบบ: โอนธนาคาร(แนบสลิป), QR PromptPay (ไม่มีชำระเงินปลายทางแล้ว) + สถานะการจัดส่ง "จัดส่งสินค้าให้กับบริการขนส่งเรียบร้อยแล้ว" + เลขพัสดุ
7. โปรไฟล์: เปลี่ยนรูป/ชื่อ/เบอร์/รหัสผ่านได้ (เมนูซ้าย "โปรไฟล์ของฉัน") ถ้าไม่มีรูปแสดงอักษรตัวแรกของชื่อ

## ขั้นตอนการชำระเงิน
| วิธี | ลูกค้า | ร้านค้า |
|---|---|---|
| โอนธนาคาร | เห็นเลขบัญชี → โอน → แนบสลิป (บังคับ) | หน้าคำสั่งซื้อ: อนุมัติ หรือ ไม่อนุมัติ(พร้อมเหตุผล) |
| QR PromptPay | สแกน QR (ยอดเงินใส่ให้แล้ว) → กด "ฉันชำระเงินแล้ว" (แนบสลิปได้) | ตรวจสอบแล้วอนุมัติ |

- หน้าคำสั่งซื้อของลูกค้าตรวจสถานะการชำระเงินอัตโนมัติทุก 8 วินาที เมื่อร้านอนุมัติ หน้าจะอัปเดตเอง
- อนุมัติการชำระเงินแล้ว คำสั่งซื้อจะเปลี่ยนจาก "รอดำเนินการ" เป็น "กำลังจัดเตรียม" อัตโนมัติ
- โอน/PromptPay ที่ยังไม่ชำระ จะเปลี่ยนเป็น "จัดส่งแล้ว/สำเร็จ" ไม่ได้
- ยอดขายในแดชบอร์ดนับเฉพาะคำสั่งซื้อที่ชำระแล้วและไม่ถูกยกเลิก

## ข้อจำกัดที่ควรรู้
การตรวจสถานะ PromptPay เป็นแบบ "ลูกค้าแจ้งชำระ + ร้านอนุมัติ" ระบบยังไม่ตรวจยอดเข้าบัญชีธนาคารให้อัตโนมัติ
เพราะต้องใช้บริการเชื่อมต่อธนาคาร/Payment Gateway (เช่น Omise, 2C2P, SCB Open API) ซึ่งต้องสมัครและมีคีย์ของร้านเอง
